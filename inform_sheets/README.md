# inform_sheets: one reference workbook, and what the rest of this folder is

**The single reference for the Core is `data-source/tanzania-inform-risk.xlsx`**, the INFORM Sub-national
SADC 2024 *Country Model Template* for Tanzania (release December 2024 v1.0; sha256 recorded in
`src/data/tanzania-inform-risk.json` metadata, 170 units). `npm run build:core` rebuilds the Core from it
and nothing else; `dataset.integrity.test.ts` proves the Core equals it leaf by leaf. No file in this
folder is a reference for a score (issue OPS-02).

| File | What it is | Status |
|---|---|---|
| `INFORM.xlsm` | The SADC regional model file (every SADC country, one sheet), from which the Tanzanian template was cut | Context only; never read by the site or the scripts |
| `INFORM.csv`, `INDICATOR.csv`, `METADATA.csv`, `SUBDIVISIONS.csv`, `SUB_NATIONAL_1.csv`, `SUB_NATIONAL_2.csv`, `DATA_NATION.csv`, `ANALYSIS.csv`, `admin_analysis.csv` | CSV exports of the regional file's sheets, made for the first reading of the model in 2025 | Historical; superseded by the workbook sources in `src/data/inform-workbook-sources.json` (built by `scripts/build-workbook-sources.py` from the reference workbook's Metadata sheet) |
| `INFORM_TZ_Collection_Tool.xlsx`, `INFORM_TZ_Collection_Benchmark.xlsx` | The NORMAL data collection tool and its benchmark (every council, the 53 workbook indicators and the 8 Benchmark 2026 activations in their measured units), generated by `scripts/build-collection-tool.py` and `scripts/fill-collection-tool.py`; see `docs/DATA_COLLECTION_TOOLS_MANUAL.md` | Generated; the tool files are git-ignored, the benchmark values are tested against the workbook (`tools.test.ts`) |
| `INFORM_TZ_Collection_Benchmark_2026.xlsx` | The collection tool with the Benchmark 2026 institutional values filled in (green cells) and a 'Benchmark 2026' sheet listing every dataset, source, period and method; generated by `scripts/fill-benchmark-2026-tool.py`; the version institutions continue from, and the file the Data portal imports back (Data control tab, or an institution's Indicators tab for its own indicators) | Generated |
| `INFORM_TZ_Advanced_Tool.xlsx`, `INFORM_TZ_Advanced_Benchmark.xlsx` | The ADVANCED tool (the 30 sub-indicators of the 12 Advancement baskets) and its benchmark, generated by `scripts/build-advanced-tool.py` and `scripts/fill-advanced-tool.py`; `node scripts/verify-advanced-tool.mjs` recalculates the benchmark in LibreOffice and compares every component cell with the engine | Generated and verified |
| `satellite_maps/*.tif` | Tanzania rasters of the Earth Engine extractions behind the Advancement members (NDVI, soil moisture, hot days, wind, 1-day rainfall), kept for inspection | Derived products; the member values are the council CSVs in `data-source/` |
| `TZ_INFORM_model.xlsx`, `INFORM.xlsx`, `wx_forecast_input_data.xlsx`, the fire and ACTF spreadsheets, `FIRE DATA/`, `inform_tools/` (copies of the tools and benchmarks handed out), `INFORM_Tanzania_Subnational_Risk.pptx` | Local working copies and raw materials that are **not tracked in git** (`TZ_INFORM_model.xlsx` is an older SADC-wide copy with broken `#DIV/0!` caches and a different reference population) | Not references; delete or archive freely |

Rule: a value enters the Core only from the reference workbook or through the Data portal with a citable
source; a value enters the Advancement layer only from a `data-source/` file with a documented method
(`docs/HAZARD_REPRODUCTION.md`).
