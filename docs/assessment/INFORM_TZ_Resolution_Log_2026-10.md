# INFORM Tanzania: resolution log (October 2026)

Status of the 143 issues in `INFORM_TZ_Issue_Matrix_2026-10.xlsx` after the first resolution pass of 2026-10-09. All changes are in the local working tree (nothing committed or deployed); each was verified with `npm run check` (tsc, eslint, vitest: 41 files, 409 tests) and with screenshots of the local site.

Status counts: **125** Resolved locally (uncommitted); **9** Open; disclosed on the Methodology page; **6** In progress; **3** Open.

## Principle applied

The Core is the authentic INFORM Sub-national SADC 2024 workbook, reproduced exactly and extended only by values institutions enter by the INFORM method with a citable source. Every Tanzanian improvement belongs to a documented Advancement layer, shown apart from the Core and never mixed into it. The displayed methodology describes what the engine does.
